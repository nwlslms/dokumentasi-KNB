# Soal 10 - Format Nilai Akademik

## Deskripsi
Diberikan nama mahasiswa (tanpa spasi), NIM, dan nilai akhir.

Tampilkan data tersebut dengan format yang ditentukan.

## Input
Baris pertama berisi string `nama`.

Baris kedua berisi bilangan bulat `nim`.

Baris ketiga berisi bilangan real `nilai`.

## Output
Format:
```text
Mahasiswa : <nama>
NIM       : <nim>
Nilai     : <nilai>
```

Nilai harus ditampilkan dengan tepat 2 angka di belakang koma.

## Contoh Input
```text
Sinta
230101
89.5
```

## Contoh Output
```text
Mahasiswa : Sinta
NIM       : 230101
Nilai     : 89.50
```
