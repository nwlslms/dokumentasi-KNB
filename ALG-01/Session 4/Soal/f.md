# Soal 6 - Konversi Suhu

## Deskripsi
Diberikan suhu dalam Celcius. Konversikan ke Fahrenheit menggunakan rumus:

```text
F = (9/5) × C + 32
```

## Input
Sebuah bilangan real `C`.

## Output
Tampilkan suhu Fahrenheit dengan 2 angka di belakang koma.

## Contoh Input
```text
25
```

## Contoh Output
```text
77.00
```
