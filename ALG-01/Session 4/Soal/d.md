# Soal 4 - Biodata Sederhana

## Deskripsi
Baca nama (tanpa spasi) dan umur seseorang, lalu tampilkan kembali dalam format tertentu.

## Input
Baris pertama berisi string `nama`.

Baris kedua berisi bilangan bulat `umur`.

## Output
Tampilkan:
```text
Nama: <nama>
Umur: <umur>
```

## Contoh Input
```text
Budi
21
```

## Contoh Output
```text
Nama: Budi
Umur: 21
```
