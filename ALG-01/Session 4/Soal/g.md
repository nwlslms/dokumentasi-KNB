# Soal 7 - Operasi Dasar

## Deskripsi
Diberikan dua bilangan bulat `A` dan `B`.

Tampilkan hasil:
- Penjumlahan
- Pengurangan
- Perkalian

## Input
Dua bilangan bulat `A` dan `B`.

## Output
Format:
```text
Jumlah = <hasil>
Selisih = <hasil>
Kali = <hasil>
```

## Contoh Input
```text
8 3
```

## Contoh Output
```text
Jumlah = 11
Selisih = 5
Kali = 24
```
