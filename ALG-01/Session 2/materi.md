- [x] Tipe Data
    - Bilangan bulat
        `-1, 0, 1, 2, 3`
        ```c
        short a;
        int b;
        long c;
        long long d;
        ```
    - Bilangan desimal
        `0.0; 0.1; 0.3; 1.1`
        ```c
        float a;
        double b;
        ```
    - Characters
        `'1', 'A', 'b', '*'`
        ASCII
        ```c
        char karakter;
        char str [21];
        ```
    - Logika
        `True / False; 1 / 0`
        ```c
        short logika; // ENIH
        int logika;
        long logika;
        long long logika;
        ```
