# Soal 2 - Cek Segitiga

## Deskripsi
Diberikan tiga panjang sisi segitiga A, B, dan C.

Tentukan:

- `SEGITIGA SAMA SISI`
- `SEGITIGA SAMA KAKI`
- `SEGITIGA SEMBARANG`

## Constraint
- 1 ≤ A,B,C ≤ 1000

## Input
```txt
A B C
```

### Contoh Input
```txt
5 5 8
```

## Output
```txt
SEGITIGA SAMA KAKI
```

## Notes
```txt
   /\
a /  \ b
 /    \
/      \
--------
    c
```
