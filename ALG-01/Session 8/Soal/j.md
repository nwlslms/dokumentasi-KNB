# Soal 10 - Bilangan Spesial

## Deskripsi
Diberikan sebuah bilangan bulat `N`.

Tentukan kategori bilangan tersebut:

- `KELIPATAN 3 DAN 5` jika habis dibagi 3 dan 5.
- `KELIPATAN 3` jika hanya habis dibagi 3.
- `KELIPATAN 5` jika hanya habis dibagi 5.
- `BUKAN KELIPATAN KEDUANYA` jika tidak memenuhi ketiga kondisi di atas.

## Constraint
- 1 ≤ N ≤ 10^9

## Input
Sebuah bilangan bulat `N`.

### Contoh Input 1
```txt
45
```

### Contoh Output 1
```txt
KELIPATAN 3 DAN 5
```

### Contoh Input 2
```txt
18
```

### Contoh Output 2
```txt
KELIPATAN 3
```

### Contoh Input 3
```txt
25
```

### Contoh Output 3
```txt
KELIPATAN 5
```

### Contoh Input 4
```txt
7
```

### Contoh Output 4
```txt
BUKAN KELIPATAN KEDUANYA
```
