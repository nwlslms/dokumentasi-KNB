# Soal 5 - Nilai Akhir Mahasiswa

## Deskripsi
Nilai akhir dihitung dengan rumus:

```txt
20% Tugas
30% Quiz
50% UAS
```

Tentukan nilai huruf:

| Nilai | Huruf |
|---------|---------|
| >= 85 | A |
| >= 70 | B |
| >= 55 | C |
| >= 40 | D |
| < 40 | E |

## Constraint
- 0 ≤ nilai ≤ 100

## Input
```txt
tugas quiz uas
```

### Contoh Input
```txt
85 70 90
```

## Output
```txt
A
```
