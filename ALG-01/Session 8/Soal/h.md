# Soal 8 - Mesin ATM

## Deskripsi
Sebuah ATM hanya dapat mengeluarkan uang dalam kelipatan Rp50.000.

Diberikan nominal yang ingin diambil oleh nasabah. Tentukan apakah transaksi dapat dilakukan atau tidak.

Jika nominal merupakan kelipatan Rp50.000 maka transaksi berhasil, jika tidak maka transaksi ditolak.

## Constraint
- 50.000 ≤ nominal ≤ 10.000.000

## Input
Sebuah bilangan bulat `nominal`.

### Contoh Input 1
```txt
350000
```

### Contoh Output 1
```txt
BERHASIL
```

### Contoh Input 2
```txt
375000
```

### Contoh Output 2
```txt
DITOLAK
```
