# Soal 3 - Seleksi Beasiswa

## Deskripsi
Mahasiswa mendapatkan beasiswa jika:

- IPK ≥ 3.50 DAN
- Penghasilan orang tua ≤ 5000000

Jika tidak memenuhi syarat, mahasiswa tidak lolos.

## Constraint
- 0.00 ≤ IPK ≤ 4.00
- 0 ≤ penghasilan ≤ 100000000

## Input
```txt
ipk
penghasilan
```

### Contoh Input
```txt
3.78
4000000
```

## Output
```txt
LOLOS
```
