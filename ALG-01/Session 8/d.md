# Soal 4 - Penukaran Uang

## Deskripsi
Diberikan sejumlah uang N.

Hitung berapa lembar yang dibutuhkan jika hanya tersedia pecahan:

- 100000
- 50000
- 20000
- 10000
- 5000
- 2000
- 1000

Gunakan jumlah lembar seminimal mungkin.

## Constraint
- 1000 ≤ N ≤ 10000000
- N kelipatan 1000

## Input
```txt
N
```

### Contoh Input
```txt
286000
```

## Output
```txt
100000 : 2
50000 : 1
20000 : 1
10000 : 1
5000 : 1
2000 : 0
1000 : 1
```
