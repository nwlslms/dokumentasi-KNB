# Soal 1 - Tarif Parkir

## Deskripsi
Sebuah tempat parkir menerapkan aturan:

- 2 jam pertama : Rp5.000
- Setiap jam berikutnya : Rp2.000

Diberikan lama parkir dalam jam. Hitung total biaya parkir.

## Constraint
- 1 ≤ jam ≤ 24

## Input
```txt
jam
```

### Contoh Input
```txt
5
```

## Output
```txt
11000
```

## Penjelasan
2 jam pertama = 5000

3 jam berikutnya = 3 × 2000

Total = 11000
