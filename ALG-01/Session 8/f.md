# Soal 6 - Login Sistem

## Deskripsi
Sebuah sistem mempunyai:

```txt
Username : admin
Password : alg01
```

Jika username dan password benar, tampilkan:

```txt
LOGIN BERHASIL
```

Jika salah satu salah:

```txt
LOGIN GAGAL
```

## Input
```txt
username
password
```

### Contoh Input
```txt
admin
alg01
```

## Output
```txt
LOGIN BERHASIL
```
