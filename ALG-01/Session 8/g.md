# Soal 7 - Tahun Kabisat dan Abad

## Deskripsi
Diberikan sebuah tahun.

Jika tahun tersebut:

- Kabisat dan kelipatan 100 → tampilkan `KABISAT ABAD`
- Kabisat → tampilkan `KABISAT`
- Selain itu → tampilkan `BUKAN KABISAT`

## Constraint
- 1 ≤ tahun ≤ 10000

## Input
```txt
tahun
```

### Contoh Input
```txt
2000
```

## Output
```txt
KABISAT ABAD
```
